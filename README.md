# 물리치료사를 위한 병리학 — 문제풀이 학습 웹앱

문제를 풀고, 해설로 배우고, 잊을 때쯤 다른 문제로 다시 만나는 병리학 학습 웹앱.

- 학습 모드: 한 문제씩 → 확신도(확실/애매/찍음) → 즉시 해설(정답 근거 · 보기 분석 · 핵심 정리 · 기억법 · 임상 연결) → 오답이면 틀린 이유 선택
- 간격 복습: 개념 단위, 1 → 3 → 7일, 같은 개념의 다른 변형 문항으로 재출제
- 모의고사(20문항), 핵심 정리 노트, 오답 노트, 내 학습 통계, 교수 학습 분석(엑셀)
- 정적 SPA + Supabase(pa_ 테이블). 장 데이터: `js/data/chNN.js`
